# Chef IDK Vision

## Mission
End the nightly "What's for dinner?" conversation by giving families one place to decide, shop, cook, and use leftovers.

## Core Features
- Chef IDK AI assistant
- Cook Tonight
- Eat Out
- Smoker Mode
- Grocery Lists
- Family Profiles
- Pantry Tracking
- Leftover Planner
- Weekly Meal Planning

## Future Features
- Pantry Scan using phone camera
- Receipt Scanner
- Walmart integration
- Kroger / Costco / Sam's integration
- Family voting for dinner
- Push notifications
- Restaurant recommendations
- Premium subscription

## MVP Goal
Build a polished web app that real families use weekly before expanding to iPhone and Android.

## Guiding Principle
Every feature must make deciding, buying, cooking, or reusing food easier.
